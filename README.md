# Birikimim

Kişisel birikim, altın ve döviz takip uygulaması (PWA).

- Tüm veriler yalnızca cihazda (IndexedDB) saklanır; hiçbir sunucuya gönderilmez.
- İnternete yalnızca altın ve döviz fiyatları için çıkılır (finans.truncgil.com).
- Yedekler JSON dosyası olarak kullanıcının seçtiği yere kaydedilir.
